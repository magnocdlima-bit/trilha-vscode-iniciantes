# Trilha de Desenvolvimento: VS Code

Material de estudo para iniciantes, com uma trilha interativa sobre o Visual Studio Code.

## Conteúdo

- `trilha_vs_code_completa_iniciantes_v3.html`: tutorial interativo, acessível localmente pelo navegador.
- `workbench_vscode_iniciantes.png`: imagem de apoio usada pelo material.

## Uso

Abra `trilha_vs_code_completa_iniciantes_v3.html` em um navegador moderno. A imagem deve permanecer na mesma pasta para que os recursos locais sejam encontrados.

## Publicação

Este projeto está preparado como repositório de estudo público. O material permanece independente dos demais projetos em `Desktop/Projetos`.
